Configurações

IA: várias IAs trabalhando juntas, escolhidas automaticamente para ser rápido e preciso.
A IA é baixada uma única vez e depois roda no seu aparelho, sem custo e sem conta. Precisa do Chrome ou Edge atualizados. É mais simples que o Claude: para materiais grandes ela lê trechos de cada vez — use o campo “Foco” para direcionar.
Como instalar: baixe em ollama.com/download, instale e rode no PowerShell:
ollama pull qwen3:4b-instruct (recomendado, ~2,5 GB, rápido)
PC mais forte: ollama pull qwen3:8b · Para ler fotos: ollama pull gemma3:4b
Depois clique em “Detectar modelos”.

A chave fica salva só neste navegador e é enviada apenas para api.anthropic.com. Crie uma em console.anthropic.com → API Keys.
